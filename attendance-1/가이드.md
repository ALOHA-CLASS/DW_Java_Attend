# attendance-1 가이드 (STEP 1 — 1일차 프로젝트)

1일차에서 배운 문법(입출력, 자료형, 조건문, 반복문, 메소드)만 사용해 만드는 **기본 콘솔 출석 체크기**입니다. 클래스 설계나 컬렉션은 아직 사용하지 않고, 배열과 `static` 변수로 출석부를 관리합니다.

## 사용한 문법 매핑

| 문법 요소 | 코드 위치 |
|---|---|
| 입출력(Scanner) | `main`, `checkAttendance`, `checkEarlyLeave` 의 `sc.nextInt()`, `sc.nextLine()` |
| 자료형 | `String[] names`, `int count`, `final int` 상수들 |
| 조건문 | `switch(menu)`, 지각/조퇴 판정용 `if-else` |
| 반복문 | 메뉴 반복용 `while`, 출석부 출력/검색용 `for` |
| 메소드 | `printMenu`, `checkAttendance`, `checkEarlyLeave`, `findStudent`, `printAll` 로 기능 분리 |

## 단계별 작업 순서

1. **메뉴 출력 구조 만들기** — `printMenu()`로 화면을 그리고, `while` 반복문으로 종료(4번) 전까지 메뉴를 계속 보여줍니다.
2. **출석 체크 기능 구현** — `checkAttendance()`에서 이름과 등원 시각(시, 분)을 입력받아, `if` 조건으로 9시 30분 기준 출석/지각을 판단하고 배열에 저장합니다.
3. **조퇴 체크 기능 구현** — `checkEarlyLeave()`에서 이름으로 기존 기록을 찾아(`findStudent`), 하원 시각이 15시 이전이면 조퇴로 상태를 변경합니다.
4. **전체 출석부 출력** — `printAll()`에서 `for` 반복문으로 저장된 모든 학생의 상태를 출력합니다.
5. **메소드로 기능 분리** — 각 기능을 별도 메소드로 나누어 `main`은 메뉴 분기만 담당하도록 정리합니다.

## 실행 방법

1. `src/App.java`를 열고 Run 버튼으로 실행합니다.
2. 터미널에 메뉴 번호(1~4)를 입력하고 안내에 따라 이름/시각을 입력합니다.
3. 3번을 선택해 전체 출석부가 잘 기록되는지 확인합니다.
