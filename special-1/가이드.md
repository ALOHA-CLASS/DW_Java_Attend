# special-1 가이드 (1일차 문법 예제)

09/14(월) 1부 수업 "자바 기초 & 제어문 / 기본 객체"에서 배우는 문법 요소를 패키지별로 정리한 예제 프로젝트입니다.

## 폴더 구조

```
src/
  _01/기본구조/   Ex01~Ex03.java
  _02/변수선언/   Ex01~Ex03.java
  _03/입출력/     Ex01~Ex03.java
  _04/자료형/     Ex01~Ex04.java
  _05/조건문/     Ex01~Ex04.java
  _06/반복문/     Ex01~Ex04.java
  _07/메소드/     Ex01~Ex04.java
```

패키지명은 `_01.기본구조` 처럼 `_번호.주제` 형태이며, 각 폴더 안의 `ExNN.java` 파일 하나하나가 `main` 메소드를 가진 독립 실행 예제입니다.

## 단계별 학습 순서

1. **_01.기본구조** — 자바 프로그램이 클래스와 `main` 메소드로 이루어짐을 확인합니다. `Ex01`~`Ex03`을 순서대로 실행해보며 주석 종류와 메소드 조합 흐름을 익힙니다.
2. **_02.변수선언** — 변수 선언/초기화, 명명 규칙, `final` 상수, 지역변수 스코프를 학습합니다.
3. **_03.입출력** — `Scanner`로 문자열/숫자를 입력받고, `printf`로 형식화된 출력을 해봅니다. 실행 시 콘솔에 값을 직접 입력해야 합니다.
4. **_04.자료형** — 정수형/실수형/문자형/불리언 8가지 기본 자료형과 형변환(묵시적/명시적), 자료형의 범위를 확인합니다.
5. **_05.조건문** — `if-else`, 다중 `else if`, `switch`, 삼항 연산자로 조건에 따라 분기하는 방법을 익힙니다.
6. **_06.반복문** — `while`, `do-while`, `for`, 중첩 반복문과 `break`/`continue`를 학습합니다.
7. **_07.메소드** — 매개변수/반환값의 유무에 따른 메소드 작성법을 익히고, `Ex04`에서 지금까지 배운 내용(입출력+조건문+메소드)을 종합한 간단 계산기를 만들어봅니다.

## 실행 방법

1. VS Code에서 원하는 `ExNN.java` 파일을 엽니다.
2. 우측 상단의 ▷(Run) 버튼을 누르거나, 파일 안 `main` 메소드 위의 `Run` 코드렌즈를 클릭합니다.
3. `Scanner`를 사용하는 예제는 하단 터미널에 값을 입력한 뒤 Enter를 눌러 진행합니다.
