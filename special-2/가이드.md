# special-2 가이드 (2일차 문법 예제)

09/15(화) 1부 수업 "객체지향 설계 & 컬렉션"에서 배우는 문법 요소를 패키지별로 정리한 예제 프로젝트입니다.

## 폴더 구조

```
src/
  _08/클래스/       Ex01~Ex03.java
  _09/객체생성/     Ex01~Ex03.java
  _10/객체사용/     Ex01~Ex03.java
  _11/생성자/       Ex01~Ex03.java
  _12/오버로딩/     Ex01~Ex03.java
  _13/상속/         Ex01~Ex03.java
  _14/오버라이딩/   Ex01~Ex03.java
  _15/인터페이스/   Ex01~Ex03.java
  _16/컬렉션/       Ex01~Ex04.java
```

각 `ExNN.java` 파일은 필요한 경우 예제용 보조 클래스(예: `Car`, `Person`, `Animal`)를 같은 파일 안에 함께 정의하고, `public class ExNN`의 `main` 메소드에서 이를 사용합니다.

## 단계별 학습 순서

1. **_08.클래스** — 필드와 메소드로 클래스를 정의하는 방법과 필드 기본값을 확인합니다.
2. **_09.객체생성** — `new` 키워드로 객체를 여러 개 만들고, 객체 배열과 참조 비교(`==`)를 학습합니다.
3. **_10.객체사용** — 필드 접근/수정, 메소드 호출, 객체를 매개변수로 전달하거나 반환하는 방법을 익힙니다.
4. **_11.생성자** — 매개변수가 있는 생성자, `this` 키워드, 생성자 오버로딩을 학습합니다.
5. **_12.오버로딩** — 매개변수 개수/타입이 다른 메소드를 같은 이름으로 정의하는 방법을 익힙니다.
6. **_13.상속** — `extends`, `super`, `protected` 접근제어자로 부모-자식 관계를 구성합니다.
7. **_14.오버라이딩** — `@Override`로 부모 메소드를 재정의하고, 다형성과 `toString()` 재정의를 학습합니다.
8. **_15.인터페이스** — `interface`/`implements`로 규격을 정의하고, 다중 구현과 인터페이스 타입 다형성을 익힙니다.
9. **_16.컬렉션** — `ArrayList`, `HashSet`, `HashMap`과 `Collections.sort`를 활용한 자료 관리를 학습합니다.

## 실행 방법

1. 실행하려는 `ExNN.java` 파일을 열고 Run 버튼을 누릅니다.
2. 콘솔 출력 결과와 코드를 비교하며 동작을 이해합니다.
